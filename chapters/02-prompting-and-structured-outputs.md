# 02 - Prompting and structured outputs

## Learning promise

Learners can turn an ambiguous finance request into a testable prompt and a typed
response contract.

## Deck narrative

Instructions → context → examples → constraints → structured outputs → validation
→ failure handling.

## Notebook lab

Extract a financial KPI table into a Pydantic model and validate edge cases.

## Checkpoint

1. What belongs in the prompt versus the schema?
2. Why can a valid JSON response still be wrong?
3. Which constraints should be enforced in Python?
