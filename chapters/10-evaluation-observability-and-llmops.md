# 10 - Evaluation, observability, and LLMOps

## Learning promise

Learners can define and monitor quality, reliability, latency, cost, and operational
health for a complete AI system.

## Deck narrative

Test cases → retrieval metrics → answer metrics → tool correctness → traces →
latency and cost → model serving → monitoring → release gates.

## Notebook lab

Run a small evaluation suite and analyze retrieval, answer, and agent failures.

## Checkpoint

1. Which failures require deterministic tests?
2. When is an LLM judge appropriate?
3. Why are infrastructure metrics insufficient for product quality?
