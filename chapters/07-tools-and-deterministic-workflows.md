# 07 - Tools and deterministic workflows

## Learning promise

Learners can expose typed financial functions to a model without surrendering
control of the application workflow.

## Deck narrative

Function → schema → tool selection → validation → execution → result → workflow
state → approval boundaries.

## Notebook lab

Build a price tool, a filing tool, and a deterministic research workflow.

## Checkpoint

1. What should never be delegated to the model?
2. Why must tool arguments be validated twice?
3. Which tool calls require explicit user approval?
