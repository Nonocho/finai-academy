# 09 - Multi-agent financial research

## Learning promise

Learners can decide when specialist agents improve a financial research task and
when they only add cost and complexity.

## Deck narrative

Task decomposition → supervisor → specialist tools → shared state → synthesis →
conflict resolution → execution trace.

## Notebook lab

Coordinate a price analyst, filing analyst, and synthesizer under a bounded
supervisor.

## Checkpoint

1. Why should specialists have different tool scopes?
2. What information belongs in shared state?
3. When is a single deterministic workflow better?
