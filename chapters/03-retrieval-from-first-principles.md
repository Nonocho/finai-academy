# 03 - Retrieval from first principles

## Learning promise

Learners can build and evaluate a lexical retrieval baseline before introducing
embeddings.

## Deck narrative

Knowledge limits → corpus → indexing → TF-IDF → similarity → top-k → retrieval
metrics → baseline discipline.

## Notebook lab

Implement TF-IDF retrieval over a small financial corpus and measure recall at k.

## Checkpoint

1. Why is a simple baseline valuable?
2. What does top-k change?
3. Which query types favor exact lexical matching?
