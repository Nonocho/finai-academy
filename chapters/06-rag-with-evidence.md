# 06 - RAG with evidence

## Learning promise

Learners can build answers whose factual claims are traceable to retrieved evidence.

## Deck narrative

Retrieve → construct context → answer → cite → verify → abstain → stream.

## Notebook lab

Generate an answer with claim-level citations and reject unsupported claims.

## Checkpoint

1. What makes a citation useful rather than decorative?
2. How should the system respond when evidence conflicts?
3. What is the difference between groundedness and correctness?
