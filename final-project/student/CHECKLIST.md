# Capstone integration checklist

## 0–10 minutes: establish the baseline

- [ ] Launch `final-project/student/streamlit_app.py`.
- [ ] Confirm the fixed reference mission and all four incomplete statuses are visible.
- [ ] Run `final-project/student/verify.py` and read the four named diagnostics.
- [ ] Open `integration.py`; keep changes inside the four function bodies.

## 10–40 minutes: complete the four seams

- [ ] Wire the certified, company-filtered retriever.
- [ ] Register only discovered, approved analyst read capabilities.
- [ ] Require NVIDIA and Schneider Electric document evidence at the gate.
- [ ] Assemble the existing display-safe public briefing view.
- [ ] Re-run the verifier after each seam and keep failures independent.

## 40–55 minutes: verify the complete route

- [ ] Confirm the recorded reference mission passes.
- [ ] Confirm citation integrity and all five deterministic metrics pass.
- [ ] Confirm local persistence passes without exposing a path.
- [ ] Confirm stdout contains one standalone `CAPSTONE_PASS` and stderr is empty.
- [ ] Confirm no API key, network connection, Tavily, or Ollama is required.

## 55–60 minutes: final review

- [ ] Remove debug prints and any copied provider details.
- [ ] Check that no personal path, credential, trading action, or investment advice was added.
- [ ] If working in a pair, explain one seam each and review the other two together.
