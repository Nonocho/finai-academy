# Course architecture

## Communication job

By the end, technically curious finance professionals should be able to design,
build, and evaluate a trustworthy AI research system because they understand every
layer from model inference to production observability.

## Three-layer content model

### Slides

Slides explain mental models, trade-offs, architecture, and decision criteria.
They are not code transcripts.

### Notebooks

Notebooks make one concept observable at a time. Every notebook contains:

1. learning objectives;
2. a minimal baseline;
3. one controlled experiment;
4. a guided implementation;
5. checkpoint questions;
6. an optional challenge;
7. a concise takeaway.

### Final project

The capstone integrates reusable package code into FinResearch Copilot. The final
application is not developed as one giant notebook.

## Learning sequence

```text
Model behavior
  → reliable outputs
  → retrieval
  → grounded generation
  → tools
  → workflows
  → agents
  → multi-agent orchestration
  → evaluation
  → production
```

## Adaptation principle

The full curriculum is the source product. Short formats select from it:

- never delete the conceptual dependencies;
- compress examples before compressing explanations;
- keep evaluation and safety in every format;
- preserve the product demo at the beginning and the capstone at the end.
