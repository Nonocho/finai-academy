# First Finance course visual system

## Identity

- Organisation: **First Finance**
- Course: **AI Engineering for Asset Management**
- Signature: **First Finance - Arnaud Demes**
- Logo: none
- Visual relationship: ScaleNow color system, independent course identity

## Palette

| Token | Hex | Role |
|---|---|---|
| Deep Navy | `#051C2A` | Primary text, dark backgrounds, architecture anchors |
| Royal Blue | `#1F40CB` | Primary emphasis, important transitions |
| Cyan | `#00A2EB` | Data, retrieval, active states, highlights |
| Signal Orange | `#F07D00` | Risks, warnings, human decisions |
| Charcoal | `#373738` | Secondary text |
| Mid Gray | `#9E9FA2` | Dividers, metadata, inactive states |
| Off White | `#F5F5F5` | Main light background |
| White | `#FFFFFF` | Contrast and negative space |

## Typography

- Display: EB Garamond or Georgia fallback
- Body: Roboto or Arial fallback
- Code and labels: Roboto Mono or Consolas fallback

## Presentation language

- Minimal title slide.
- Flat editorial compositions rather than dashboard-style card grids.
- Generous but purposeful whitespace.
- Architecture diagrams use Deep Navy for systems, Cyan for data flows, Royal
  Blue for model actions, and Orange for risks or human approval.
- Avoid decorative gradients unless they communicate a transition.
- No ScaleNow logo or derivative logo mark.

## Footer

Every audience-facing slide except the title slide includes:

```text
First Finance - Arnaud Demes                                  [slide number]
```

## Accessibility

- Maintain WCAG-conscious contrast.
- Do not encode meaning through color alone.
- Use direct labels on charts when practical.
- Avoid body copy below 16 pt.
